# P2.1 — Hướng dẫn và biên bản kiểm chứng vòng đời xác thực

**Ngày lập:** 03/11/2026. **Trạng thái:** **CHƯA CHẠY**. Tài liệu, test source và Postman contract đã được chuẩn bị; người dùng sẽ chạy build/test/dev và ghi kết quả sau. Không dùng trạng thái này để kết luận P2.1 đạt.

## 1. Phạm vi cần kiểm chứng

P2.1 chỉ được chốt sau khi có bằng chứng cho toàn bộ chuỗi sau:

- Login, `/me`, refresh rotation/replay và logout phía server.
- Gate mật khẩu tạm và `POST /api/v1/auth/change-password`.
- Reset mật khẩu, khóa/mở khóa và thu hồi toàn bộ phiên qua application use case nội bộ.
- Access/refresh token cũ bị chặn theo `sid`/`ver`, kể cả sau restart.
- Hai refresh cạnh tranh không cùng thành công; refresh cạnh tranh với revoke không làm token sống lại.
- Response nhạy cảm có `Cache-Control: no-store`, không tạo session cookie và không lộ password/token trong lỗi.

## 2. Chạy suite tự động

Từ thư mục repository:

```powershell
docker compose -p bpm-test -f compose.test.yaml up --build --abort-on-container-exit --exit-code-from tests
$testExitCode = $LASTEXITCODE
docker compose -p bpm-test -f compose.test.yaml logs tests
```

Kỳ vọng `$testExitCode` bằng `0`. Lưu log/báo cáo cần thiết trước khi dọn container. Không dùng lệnh xóa volume của stack dev để chạy test.

## 3. Chạy stack dev và smoke test thủ công

```powershell
docker compose up --build -d --wait --wait-timeout 180
Invoke-RestMethod http://localhost:8080/actuator/health
```

Kỳ vọng health trả `status: UP`. Tạo fixture dev theo README, cấu hình các biến secret chỉ trong Postman environment local, rồi chạy tuần tự:

1. `Login` → lưu access/refresh token.
2. `Get Current User (Me)` → 200 và không có password hash/refresh token.
3. `Refresh Token` → token mới; dùng lại refresh token cũ phải 401 và revoke cả grant.
4. Login lại, chạy `Change Password` → 200; access/refresh token cũ phải 401.
5. Login bằng mật khẩu cũ phải 401; login bằng mật khẩu mới phải thành công và `mustChangePassword=false`.
6. `Logout` → 200; gọi lại vẫn 200; access token cùng `sid` phải 401.
7. Restart backend rồi kiểm tra token đã revoke vẫn không dùng được.

Không ghi token hoặc mật khẩu thật vào Git, log chia sẻ hoặc tài liệu kết quả.
