## Ma trận bắt buộc

| Actor | Positive | Negative | Trạng thái |
| --- | --- | --- | --- |
| Employee | Own/participated record; candidate claim; assigned completion | Record ngoài scope; self-approval; admin API | **Policy unit đạt** cho own/participated và self-approval; endpoint/resource scope còn chờ |
| Designer | Process/form design-publish theo permission | Monitor all/task action không được gán | **Chưa có actor end-to-end trong suite hiện tại** |
| Owner | Monitor process được gán owner | Process khác; task action ngoài assignment | **Chưa có actor end-to-end trong suite hiện tại** |
| Admin | Identity/organization/RBAC, monitor all, reassign | Không tự claim/complete hoặc self-approve | **RBAC API và 403 đạt**; monitor/reassign còn chờ |
| Auditor | Audit/resource read theo scope | Create/design/publish/claim/complete | **Policy unit đạt** cho operational-action denial; scoped read còn chờ |

## Kiểm tra bổ sung

- User inactive và role INACTIVE không tạo authority.
- Thu hồi permission có hiệu lực ở request Bearer kế tiếp dù JWT snapshot còn cũ.
- List/count áp scope trước pagination; gọi detail bằng ID ngoài scope không rò metadata.
- Role update dùng revision; permission ngoài system catalog bị từ chối.
- API role/permission thiếu `identity.roles.manage` trả 403.
- Response không trả password hash, security version hoặc dữ liệu role/entity JPA thô.

Policy unit, permission catalog/RBAC API và thiếu quyền 403 đã chạy đạt. Inactive user/role, permission revocation ở request kế tiếp, scoped list/detail không rò dữ liệu và các actor chưa có end-to-end coverage còn phải kiểm tra trước khi chốt P2.3.
