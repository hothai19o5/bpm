## Ma trận

| Strategy/tình huống | Kỳ vọng | Trạng thái |
| --- | --- | --- |
| SPECIFIC_USER ACTIVE/đủ permission | Direct assignee | **ĐẠT ở unit test** |
| SPECIFIC_USER missing/inactive/requester | Failure ổn định | **MỘT PHẦN**: missing và self-approval đạt; inactive chưa có case riêng |
| DEPARTMENT | Candidate ACTIVE/đủ permission, loại requester | **ĐẠT** ở unit và DB-backed integration test |
| ROLE + department scope | Chỉ member có role ACTIVE trong đúng department | **ĐẠT ở resolver unit test**; persisted role membership chưa kiểm tra |
| REQUESTER_MANAGER | Manager hiện tại của department snapshot | **ĐẠT** ở DB-backed integration test |
| Missing/inactive/wrong-department manager | Failure, không skip task | **MỘT PHẦN**: wrong-department đạt; missing/inactive manager chưa có case riêng |
| Empty group/self-approval | Failure, không tạo candidate toàn công ty | **ĐẠT ở resolver unit test** |
| Đổi manager/membership | Resolve mới dùng dữ liệu mới; task cũ không tự đổi | **CHƯA CHẠY** |
| Restart | Directory từ PostgreSQL vẫn resolve nhất quán | **CHƯA CHẠY** |
