## Ma trận

| Strategy/tình huống | Kỳ vọng | Trạng thái |
| --- | --- | --- |
| SPECIFIC_USER ACTIVE/đủ permission | Direct assignee | **CHƯA CHẠY** |
| SPECIFIC_USER missing/inactive/requester | Failure ổn định | **CHƯA CHẠY** |
| DEPARTMENT | Candidate ACTIVE/đủ permission, loại requester | **CHƯA CHẠY** |
| ROLE + department scope | Chỉ member có role ACTIVE trong đúng department | **CHƯA CHẠY** |
| REQUESTER_MANAGER | Manager hiện tại của department snapshot | **CHƯA CHẠY** |
| Missing/inactive/wrong-department manager | Failure, không skip task | **CHƯA CHẠY** |
| Empty group/self-approval | Failure, không tạo candidate toàn công ty | **CHƯA CHẠY** |
| Đổi manager/membership | Resolve mới dùng dữ liệu mới; task cũ không tự đổi | **CHƯA CHẠY** |
| Restart | Directory từ PostgreSQL vẫn resolve nhất quán | **CHƯA CHẠY** |

P5.3 còn phải kiểm tra mapping result vào Flowable và hàng chờ ngoại lệ. Kết quả P2.4 không tự chứng minh runtime task đã tích hợp.
