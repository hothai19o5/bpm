# P2.6 - Biên bản kiểm chứng quản trị xuyên UI/API

**Ngày lập:** 03/11/2026. **Trạng thái:** CHƯA CHẠY. Chưa có kết quả build, test, dev, Postman, browser hoặc audit runtime.

## 1. Lệnh backend dự kiến

```powershell
docker compose --profile test run --rm backend-test mvn -B -ntp verify
docker compose up -d --build backend
postman collection lint postman/collections/bpm-api
postman environment lint postman/environments/local
postman workspace lint postman
```

Tên/path lệnh Postman cần đối chiếu CLI hiện tại trước khi chạy. Không lệnh nào ở trên đã được chạy trong P2.6.

## 3. Bằng chứng test source

- `OrganizationAdministrationIntegrationTest` kiểm tra API quản trị tổ chức/tài khoản, 403 và action audit tạo mới.
- `RoleAdministrationIntegrationTest` kiểm tra catalog, tạo role, 403 và action audit role.
- Các test P2.1-P2.3 hiện có tiếp tục là regression source cho token revoke, policy và invariant tổ chức.

Các test source chưa được chạy trong mốc này nên không được ghi là đạt.
